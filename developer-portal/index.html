Quickstart

Every request to the Merveil API uses an API key. Keep production keys on your server and never ship them in browser code.

curl https://api.merveil.ai/api/v1/health
-H "X-API-Key: mv_live_…"

Applications

Create separate sandbox and production applications. Credentials are hashed at rest and the secret is returned only once when created.

Security by design

Scoped keys, revocation, ownership checks, usage records and server-side secrets form the foundation. Sensitive Merveil data should only be exposed after explicit authorization and scope validation.
