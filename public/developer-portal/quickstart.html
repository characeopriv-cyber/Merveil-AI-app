Quickstart

Ship your first Merveil AI project in under 5 minutes. One prompt, one API call, one deploy.

1. Install the SDK

Node / TypeScript
Python
cURL
npm install @merveil/sdk

2. Authenticate

import { Merveil } from '@merveil/sdk';

const mv = new Merveil({
  apiKey: process.env.MERVEIL_API_KEY, // mv_live_xxx
});
Get an API key from Command Center → Docs → API keys. Keys are scoped and hashed — never share them client-side.

3. Build anything from a prompt

const project = await mv.projects.create({
  name: 'Lead Qualifier',
  kind: 'ai_agent',
  prompt: 'An AI agent that qualifies real-estate leads from WhatsApp and books viewings.',
});

for await (const stage of mv.builds.stream(project.buildId)) {
  console.log(stage.status, stage.progress + '%', stage.message);
}

console.log('Live at:', project.previewUrl);

4. Deploy

npx merveil deploy --provider vercel

5. Publish to the Merveil Interface

await mv.marketplace.publish(project.id, {
  category: 'productivity',
  priceCents: 0,
});
