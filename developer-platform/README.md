# Merveil Developer Platform

Production developer layer for the Merveil ecosystem.

## Boundary
This directory is isolated from the Citizen App. Do not modify citizen-facing features while building the platform.

## Product lifecycle
Create → Build → Run → Test → Deploy → Publish to Merveil Interface.

## Core domains
- Projects and files
- AI Builder
- Agents, tools, knowledge and memory
- Merveil SDK/API
- Builds, logs and runtime diagnostics
- Deployments, versions and rollback
- GitHub integration
- Environment and secrets management
- Publishing to Merveil Interface
- Usage, credits and permissions

## Engineering rule
No mock projects, fake build states, decorative deployment controls, or simulated production status.
