# Merveil access policy — Facebook-style open network

## Principle
**Everyone can use the social product.** Verification is a **badge**, not a wall.
Merveil is for agents, investors, companies, **and simple citizens** — same as Facebook.

## Always open (sign-in only where needed for write)
| Action | Who |
|--------|-----|
| View profiles (name, photo, listings, leads, reels) | Everyone (visitors + citizens) |
| Post property / group lead / World / Pulse | Any signed-in citizen |
| Message, call, Circle, Groups enter/post | Any signed-in citizen |
| Connect requests | Any signed-in citizen |
| Unverified badge | Shown when not KYC’d — **no feature loss** |

## Soft limits (Passport / AI — not identity wall)
| Feature | Rule |
|---------|------|
| Chat AI / chips | Daily limits by Passport tier (Core modest, paid higher) |
| AI Call (phone agent) | Professional / Investor / Company Passport |
| Boost / HD enhance credits | Earned or paid Passport |
| Paid Passport activate | KYC + wallet (money movement) |
| Payouts / withdraw | KYC required (compliance) |

## Never do
- Hide name/photo because unverified  
- Block post because not agent / not company  
- Remove Pulse listings solely for incomplete Passport  
- Require RE license to post a lead in Groups  

## Badge only
- **Verified** = Passport identity checked  
- **Unverified** = normal full profile  
- **RE verified** = optional extra trust signal when present
